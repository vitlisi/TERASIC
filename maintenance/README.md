# Retained maintenance materials

Original boot/recovery files, vendor drivers, Wi-Fi sources and MATLAB/Simscape
sources are retained because they support operation or reproduction. The Python
environment is also retained. Dated duplicate bundles and obsolete experiment
archives were permanently deleted on 9 November 2026.

[Cleanup audit](cleanup_20261109/README.md) contains hashes, relocations and the
explicit deletion record; it is not an archive of deleted datasets.
